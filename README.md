# Turtle Mass Prediction (Regression Model)

## 📊 Project Overview
This project focuses on predicting turtle body mass based on biological features using machine learning models.

## 🎯 Objective
Build and evaluate regression models to accurately predict the mass of turtles.

## 🧠 Approach
- Data preprocessing
- Feature scaling (standardization, normalization)
- Model training and comparison

## 🛠 Technologies
- Python
- Pandas, NumPy
- Scikit-learn

## 🤖 Models Used
- Linear Regression
- Lasso
- Ridge
- SGDRegressor

## 📈 Results
- Best model: Ridge Regression
- MAE: < 5
- R²: > 0.97

## 🔍 Key Insights
- Feature scaling significantly improves model performance
- Regularization helps stabilize predictions

## 🚀 Conclusion
The project demonstrates the effectiveness of linear models with proper preprocessing for regression tasks.
